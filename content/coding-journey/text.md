AI SAFEGUARD
Local Git Studio
Code save points
As I moved toward using AI agents for complex tasks, I realized that AI may break the system. I built a lightweight system that acts as a bridge between my local filesystem and AI agents. The core of this project is the "Time Machine" interface, which allows me to visualize code evolution and restore snapshots instantly, ensuring a safe environment for rapid AI-assisted iteration.
AI CONTEXT AWARENESS
A feature of this system is the AI Neural Context system. Instead of constant copy-pasting, I implemented a one-click generation tool that provides AI agents with an overview of the entire codebase. By combining this with persistent project instructions, I created a workflow where the AI never loses track of the overarching goals. This project is a management too for high-speed, agentic development, allowing me to maintain full control while the AI handles the heavy lifting of code generation.

February 2026
TRUSTED INFO
Retrieval-Augmented Generation (RAG)
CITE YOUR SOURCES
I developed the Islamic Advisor as a research into AI information integrity. To move away from the "black box" nature of standard LLMs, I created a system that prioritizes verified information over generative guessing. To achieve this, I implemented RAG workflow that forces the AI to ground its responses in a Knowledge Base API. By connecting the model to trusted, scholarly API sources, I ensured that every answer is backed by documented evidence rather than internal probability.
DECISION MAKING PROCESS
I developed a Decision-making process that occurs before a user ever sees a response: Query Analysis: The system first identifies the specific intent of the user's question. Context Retrieval: It queries the trusted API to pull relevant, verified data. Verification Loop: The model is instructed to cross-reference the retrieved data against the generated response to prevent Hallucination.

March 2026
INDUSTRY APP
Project specific software solution
Water Supply Piping Design Suite
The motivation behind HydroCalc was to modernize the often manual and fragmented process of hydraulic design in architecture. In professional practice, calculating pipe sizes for large-scale buildings requires balancing complex flow variables with rigid industrial regulations. I developed this suite to provide an environment where engineers can map out entire water supply networks, automating the transition from fixture units to precise pipe diameters.
PROFESSIONAL DEPENDENCY
A core challenge of this project involved translating legacy professional building standards into a functional digital framework. This required a deep technical dive into JIS (Japanese Industrial Standards) to digitize and reverse-engineer established pipe flow diagrams. By extracting data from reference charts, I converted analog engineering data into the precise mathematical models that the application uses for real-time calibration. This project demonstrates my ability to transform dense, industry-specific standards into a reliable software solution for industry.

February 2026 ~ (in development)
AI SWARM
AI Collaborative Network
Work distribution Hub
I wanted to design a more autonomous workflow where AI agents could check in and grab work independently. I built a "Bridge" using a long-polling Node.js server that links a remote web dashboard with my local development environment. This allows the system to constantly "listen" for new tasks and synchronize them in real-time without manual terminal commands.
AI autonomy under human supervision
The core of the design is an Auto-Accept Protocol that processes incoming task signals automatically based on pre-defined safety rules. I created a "heartbeat" for my projects, allowing for remote monitoring of my agentic workflows. While currently a functional prototype, this project serves as a strong concept for building autonomous AI Infrastructure that streamlines the deployment of AI agents across shared workloads.

January 2026 ~ (on Hold)
MARKETPLACE
Building a marketplace platform
Power Lunch Platform
The motivation behind Power Lunch was to identify and capture a unique business opportunity: a marketplace where users book lunch meetups with hosts for lessons or professional services. This was a sophisticated "full-stack" undertaking designed to handle the entire user journey. I architected a comprehensive system including secure user login and profile database, map integration, payment gateway and a custom commission-based model for platform sustainability.
TEAM PROJECT vs INDIVIDUAL PROJECTS
While I successfully built the core infrastructure, scaling the platform would require a greater backend/frontend commitment, a major marketing push for user acquisition, and significant ongoing hosting costs. I made the strategic decision to put the project on hold to prioritize more immediate, high-impact projects. This project remains a testament to my ability to identify market gaps and my pragmatic approach to development within the constraints of time and resources.
